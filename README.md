# games

HTML games, served by GitHub Pages at https://compulsed.github.io/games/.

## Adding a game

1. Put the game in its own folder with an `index.html`, e.g. `snake/index.html`.
2. Add a link to it in the list in the root `index.html`.
3. Push to `main`. It is live at `https://compulsed.github.io/games/snake/` about a minute later.

Everything in this repo is public.
